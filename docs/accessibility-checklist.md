# Manual acceptance checklist

- [ ] Acrobat Pro: inspect all five pages and field tooltips.
- [ ] Tab and Shift+Tab through fields and buttons in logical order; fix tab order in Prepare a form.
- [ ] Run accessibility checker; add document tags and repair reading order, headings, labels and form widget associations.
- [ ] Verify required fields and errors are announced; test focus after validation failures.
- [ ] Verify conditional field visibility and focus, calculation values, review summary and reset.
- [ ] Test with VoiceOver on Mac and JAWS on Windows using Acrobat desktop.
- [ ] Submit valid synthetic data and verify four related PostgreSQL rows.
- [ ] Reject missing fields, invalid date, invalid salary, missing remote location, unchecked acknowledgment and duplicate email.
- [ ] Record viewer version, OS, results and remediation. Automated checks alone do not establish Section 508 compliance.
